<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| manifest → local/CI runner | 仓库声明决定哪些能力被执行、哪些依赖为必需以及最终退出码。 |
| test process → result aggregator | 子进程退出、skip 与证据被转换为发布门禁结果。 |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|---|---|---:|---|---|---|
| T-01-01 | Tampering | high | `config/capabilities.json` / workflow parity | mitigate | schema 校验、workflow/matrix 存在性、一一对应测试；high 未关闭即阻断计划完成。 |
| T-01-02 | Repudiation | high | result aggregator | mitigate | PASS 强制 `executed + assertions_passed + evidence_id`，结果保留 environment/checked_at/reason。 |
| T-01-03 | Elevation of Privilege | high | requiredness handling | mitigate | required 依赖缺失与 required NOT RUN 均非零退出，禁止转成 SKIP/PASS。 |
| T-01-04 | Information Disclosure | low | result reason/evidence | mitigate | 结果只记录 evidence identifier 与净化原因，不记录 secret、token 或 `.env` 值。 |
</threat_model>
