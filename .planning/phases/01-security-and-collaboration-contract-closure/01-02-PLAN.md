<interfaces>
现有 Hub 权限入口：
`apply_dir_acl(username, repo_id, path, permission)`；ACL 关闭时返回原 permission，规则/subject 读取异常时返回 `None`。

现有 broken fileserver 接口：
`cfFindRestrictedPath(repoID, user string) string`；`""` 同时代表“无限制”和 RPC/parse error，`sync_api.go::checkPermission` 会缓存 300 秒。

本计划把 RPC 的字符串内容改为 JSON 对象，但不改变 searpc 的单 string 返回签名：
`{"state":"unsupported|inactive|active-valid|active-error","revision":42,"restricted_path":"/private"}`。
只有 unsupported/inactive 可走 CE 原生路径；active-error、畸形 JSON、缺 revision 或低于 token/cache revision 都拒绝。
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| search backend → Hub response | 后端候选、snippet 与 total 尚未按当前用户 ACL 裁决。 |
| Hub/Go fileserver → C Server authority | RPC 状态、revision 与 restricted path 穿越进程边界。 |
| webaccess token → content sender | 已签发 token 在 ACL 变更后可能陈旧。 |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|---|---|---:|---|---|---|
| T-01-05 | Information Disclosure | high | Search.get / both backends | mitigate | observable state 前统一 ACL，授权流重算 total/pagination，hidden body 字段负测；未关闭即阻断。 |
| T-01-06 | Elevation of Privilege | high | sync/fileserver authority error | mitigate | explicit state+revision；active error/malformed/stale 统一 deny，inactive/unsupported 才 pass-through。 |
| T-01-07 | Tampering | high | ACL revision/cache | mitigate | rule 写与 revision 原子提交，cache 绑定 revision，最终边界复查。 |
| T-01-08 | Replay | high | old webaccess token | mitigate | token 绑定 normalized path/issued revision，发送内容前 current authority check。 |
| T-01-09 | Denial of Service | medium | over-fetch authorization | mitigate | 固定 batch 上限、后端终点与既有 request timeout；安全失败返回空/403 而非无限扫描。 |
</threat_model>
