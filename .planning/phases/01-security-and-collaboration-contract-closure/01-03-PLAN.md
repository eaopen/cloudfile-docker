<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| HTTP/Hub/Go caller → Server PREPARE | caller 提供 operation id、generation 与 expected version，均不可信。 |
| native mutation → observers | 写已完成后 observer/report 只能记录事实，不能改变 outcome。 |
| lease owner session → current lease row | 同一 owner 可能持有旧 generation，身份相同不代表代际有效。 |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|---|---|---:|---|---|---|
| T-01-10 | Tampering | high | native mutation fence | mitigate | Server PREPARE 原子比较 owner+generation+expected file/commit；stale/missing 负测阻断。 |
| T-01-11 | Repudiation | high | fileop journal | mitigate | stable operation_id、一次 PREPARE、CAS terminal guard、跨入口 E2E 配对。 |
| T-01-12 | Replay | high | retry/callback operation | mitigate | logical request复用 operation_id；重复 terminal 被 guard 丢弃；下游 durable idempotency 使用同 id。 |
| T-01-13 | Elevation of Privilege | high | owner-only lock allowance | mitigate | owner 相同仍必须 exact generation/source version，release generation 强制必填。 |
| T-01-14 | Denial of Service | medium | observer failure | mitigate | report failure只日志化且 bounded；不向 client 伪装 native failure触发重写重试。 |
</threat_model>
