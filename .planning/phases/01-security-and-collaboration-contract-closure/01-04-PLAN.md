<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| browser descriptor → Chrome/Agent | 下载文件可被伪造、过期或来自未信任 origin。 |
| Agent claim/writeback → Hub | 无浏览器 cookie 的 bearer capability、ticket 与 idempotency key 穿越网络。 |
| Hub → Server fenced update | durable outcome 必须与 native commit/generation 原子语义一致。 |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|---|---|---:|---|---|---|
| T-01-15 | Spoofing | high | descriptor/claim | mitigate | v2 strict schema、trusted same-origin、digest one-time ticket、短 expiry、unsupported fail closed。 |
| T-01-16 | Replay | high | writeback retry | mitigate | SQL unique idempotency claim、stable key、prior outcome、one operation_id。 |
| T-01-17 | Tampering | high | local file writeback | mitigate | existing-file fenced RPC 比较 generation/file/commit；conflict/stale 不写不释放。 |
| T-01-18 | Information Disclosure | high | descriptor/UI/log | mitigate | descriptor 无 content/writeback/credential；UI/log不显示 ticket/capability/generation token。 |
| T-01-19 | Denial of Service | medium | heartbeat/retry | mitigate | hard expiry、3 次 bounded retry、30s Retry-After cap、session cleanup indexes。 |
</threat_model>
